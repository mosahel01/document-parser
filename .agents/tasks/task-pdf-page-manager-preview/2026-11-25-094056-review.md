# PDF page manager — rotate thumbnails, range selection, lightbox, and auto-preview (v2)

The fix commit (`ddc3073`) addresses all four issues flagged in v1: lightbox rotations now set `autoPreviewPending`, the range input shows inline errors and clears when cards are clicked manually, the lightbox image uses a rotation-aware container to prevent 90°/270° overflow, and a "Rebuilding preview…" label appears during auto-preview rebuilds. All 174 tests still pass.

## High-level view

Three of the four v1 issues are cleanly resolved. The lightbox rotate buttons now call `autoPreviewPending.current = true` after `setBook`, matching the per-card and toolbar rotate handlers. The range error is surfaced inline in red directly after the input. The lightbox container swaps `maxHeight`/`maxWidth` for 90° and 270° pages so the rotation does not escape its bounds. Manual card clicks clear the range field, eliminating the stale-display problem.

The lightbox Delete button follows a different code path from every other delete operation: it filters `book.slots` and calls `setLightboxId(null)`, but never sets `autoPreviewPending`. The toolbar Delete (`deleteSelected`), the per-card ×, and the range-triggered bulk delete all set the flag. The lightbox path was added in v1 and missed in this fix commit, leaving a single asymmetry.

### Lightbox Delete does not set auto-preview flag

The per-card delete (the `×` button in each card's toolbar row) has this guard:

```tsx
if (pages - 1 > 0 && pages - 1 <= 20) {
  autoPreviewPending.current = true
}
```

The toolbar `deleteSelected` function sets the flag conditionally on `newCount`. The lightbox Delete handler does neither:

```tsx
onClick={() => {
  setBook((current) => ({
    ...current,
    slots: current.slots.filter((s) => s.id !== lightboxId),
  }))
  setSelected(...)
  setLightboxId(null)
  // autoPreviewPending never set
}}
```

A user who opens the lightbox, deletes a page on a 15-page document, and closes the lightbox sees no preview update. The slot is removed correctly; the only breakage is the auto-preview not firing.
